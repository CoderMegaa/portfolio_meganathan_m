01 / THE BIG PICTURE

Purpose & perspective.

SHRI Connect is the mobile application associated with SAA Sublimation. It brings everyday employee and customer activities into a mobile interface, helping users manage attendance, customer leads, follow-ups, and calendar-based tasks while remaining connected to the web application.

THE OBJECTIVE

Make attendance, customer follow-ups, and daily tasks accessible through a mobile application connected to the wider ERP environment.

The business workflow

  1. 01Review the calendar
  2. 02Manage tasks & leads
  3. 03Record attendance
  4. 04Review follow-ups & reports

03 / UNDER THE HOOD

How it comes together.

Mobile application

Flutter and Dart provide the application interface and mobile functionality, with Android Studio used for development.

Connected workflows

The application integrates with Python/Django REST APIs using JSON request and response communication to connect with the SAA Sublimation web application.

Maps & notifications

Google Maps SDK supports map-related functionality. Google Maps Console manages the corresponding service configuration. Firebase and Firebase Console support push notifications; service-account JSON is used for service configuration.

MY CONTRIBUTION

Business value

Makes key customer and employee activities available on mobile, extending the SAA Sublimation operational workflow beyond the web interface.
